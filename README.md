# 2022개정교육과정 지구과학 데이터 탐구 프롬프트 워크시트

2022 개정 교육과정의 성취기준과 탐구 활동을 살펴보고, 학생이 데이터 분석 결과를 직접 검증하도록 돕는 정적 워크시트입니다. 입력한 응답은 현재 브라우저의 로컬 저장소에만 보관되며 연구자나 외부 서버로 전송되지 않습니다.

## 로컬에서 미리보기

`type="module"`과 JSON `fetch()`를 사용하므로 `index.html`을 파일 탐색기에서 직접 열지 말고 로컬 웹 서버로 실행합니다.

1. VS Code에서 이 폴더를 엽니다.
2. Extensions에서 **Live Server** 확장을 설치합니다.
3. `index.html`을 오른쪽 클릭하고 **Open with Live Server**를 선택합니다.

## 설정 바꾸기

`js/config.js`에서 다음 값을 수정합니다.

- `appVersion`: 화면 하단에 표시할 검토 버전
- `surveyUrl`: 교사 화면의 **설문 참여하기** 버튼 링크. 빈 문자열이면 버튼이 표시되지 않습니다.
- `researcher`: 화면 하단 연구자 표시
- `contact`: 문의 이메일. 빈 문자열이면 문의 링크가 표시되지 않습니다.

설문 링크는 교사가 버튼을 눌렀을 때 새 탭에서 열립니다. 이 프로그램에는 분석, 쿠키, 로그인 또는 외부 입력 전송 기능이 없습니다.

## 활동 내용 편집

활동 데이터는 `data/activities.json`의 JSON 배열에 있습니다. 항목은 다음 구조를 사용합니다.

```json
{
  "id": "es-0105",
  "subj": "es",
  "code": "12지구01-05",
  "title": "활동 제목",
  "questions": ["예시 질문"],
  "data": {
    "name": "자료 이름",
    "org": "자료 제공 기관",
    "url": "https://example.org",
    "how": "자료를 내려받는 방법"
  },
  "vars": [{ "n": "변수 이름", "u": "단위", "r": "일반적 범위" }],
  "tasks": ["분석 작업"],
  "chart": "권장 그래프",
  "predict": "예측 안내",
  "checks": [{ "t": "검증 기준", "h": "검증 힌트" }],
  "pitfalls": ["주의할 점"]
}
```

기존 항목을 편집할 때 `id`, `subj`, `code`를 포함한 필드 구조를 유지하세요. `standards.json`은 성취기준 원문, `levels.json`은 성취수준과 관련 활동 자료이므로 JSON 문법과 원문을 보존해야 합니다. 수정 뒤에는 Live Server에서 페이지를 새로고침해 결과를 확인합니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 사이트 파일과 `css/`, `js/`, `data/` 폴더를 저장소에 올립니다. `index.html`이 저장소 루트에 있어야 합니다.
3. 저장소의 **Settings → Pages**를 엽니다.
4. **Build and deployment**의 Source를 **Deploy from a branch**로 설정합니다.
5. Branch를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다.
6. Pages가 표시하는 배포 주소를 열어 데이터가 정상적으로 로드되는지 확인합니다.

## 학생용 바로가기 링크

활동 ID에서 하이픈을 빼고 버전 문자를 붙인 코드를 URL 해시로 사용합니다. 배포 주소 뒤에 `#`와 수업 코드를 붙이면 해당 활동이 학생 화면으로 바로 열립니다.

```text
https://<사용자명>.github.io/<저장소명>/#es0105a
```

수업 코드는 대소문자를 구분하지 않으며 하이픈을 생략할 수도 있습니다. 예: `ES0105-A`, `es0105a`, `ess-0303-c`.

## 브라우저 저장

마지막 화면은 `evc:last`, 활동별 응답은 `evc:<활동ID>:<버전>` 키로 브라우저 로컬 저장소에 저장됩니다. 브라우저 데이터를 지우면 저장된 워크시트 응답도 삭제되므로, 제출 전에 정리 단계에서 복사하거나 텍스트 파일로 저장하세요.
